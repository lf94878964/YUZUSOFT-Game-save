## 🔧 使用方法

1. **先備份**：找到你電腦上原本的存檔資料夾，整個複製一份保存，避免覆蓋後無法還原。
2. **下載**：點選本倉庫中對應遊戲的資料夾，下載裡面的檔案（或使用 `Code → Download ZIP` 下載整個倉庫）。
3. **找到存檔位置**：不同遊戲、不同版本（Steam 版 / 單機版）的存檔路徑可能不同，常見位置有：
   - 遊戲安裝目錄下的 `savedata` 或類似名稱的資料夾
   - `C:\Users\<你的使用者名稱>\Documents\`
   - `C:\Users\<你的使用者名稱>\AppData\Roaming\` 或 `AppData\LocalLow\`
   - Steam 版也可能位於 `Steam\userdata\<ID>\`
4. **覆蓋存檔**：把下載的檔案複製進該位置，若提示檔案已存在，選擇覆蓋。
5. **啟動遊戲**：進入遊戲後，到 CG / 場景 / 音樂鑑賞選單確認是否已全解鎖。

- 本倉庫**僅提供存檔檔案**，不包含任何遊戲本體、安裝檔或破解檔案，請先自行購買並安裝正版遊戲。
- 存檔需與**對應遊戲及版本**搭配，版本不同可能導致無法讀取。
- 使用前務必**備份原本存檔**，因覆蓋造成的進度遺失請自行承擔。
- 遊戲更新後，舊存檔有可能失效。
